## Цель работы

Научиться обрабатывать текст с помощью строк, хранить последовательности в векторе и находить данные по ключу в словаре.

## Задание

### Часть A — Соседние одинаковые

Посчитайте соседние пары одинаковых символов, включая пробелы.

### Часть B — Повторить первые два

Добавьте в конец первые два элемента. Если их меньше — добавьте все имеющиеся.

### Часть C — Отбор по порогу

Введите целый порог от −1000 до 1000. Сформируйте новый словарь из пар со значением не меньше порога и выведите его. Исходный словарь не меняйте.

### Часть D — Счёт команд по матчам

Каждая запись содержит число голов команды в одном матче, целое от 0 до 1000. Выведите для каждой команды число матчей, общую сумму и лучший результат одного матча в формате «команда матчи сумма максимум». Команды идут по алфавиту.

## Входные данные

Первой строкой вводится буква `A`, `B`, `C` или `D`, определяющая выполняемую часть.

- **A:** строка ASCII длиной до 200 символов.
- **B:** количество элементов от 0 до 100, затем целые числа от −1000 до 1000.
- **C:** количество пар от 0 до 100, пары «ключ значение», затем порог. Повторный ключ заменяет предыдущее значение.
- **D:** количество записей от 0 до 100, затем для каждой записи название команды и число голов на отдельных строках.

При недопустимом вводе программа выводит `INVALID`. Пустой результат обозначается `EMPTY`, где это предусмотрено заданием.

## Пример работы

**Входные данные (часть D):**

```
D
3
Red
2
Blue
0
Red
3
```

**Результат:**

```
Blue 1 0 0
Red 2 5 3
```

Исходный код находится в файле `lab5.cpp`.

Откройте проект в Visual Studio, соберите программу и запустите её с помощью `Ctrl + F5`.

После запуска выберите часть `A`, `B`, `C` или `D` и введите соответствующие исходные данные.
